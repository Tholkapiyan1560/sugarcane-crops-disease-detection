To address these challenges, we developed an automated image processing pipeline that stitches multiple drone images into a single high-resolution farmland map using computer vision techniques like feature matching and homography transformation. The stitched image undergoes disease detection using AI-based models and color segmentation techniques to identify affected areas. Once detected, GPS metadata from drone images is extracted and mapped, enabling precise geotagging of diseased regions. The system provides a visual representation of disease distribution and generates structured reports for farmers and agronomists. A web-based platform allows users to upload images, process data, and access geotagged disease maps in real time, facilitating targeted interventions using drones or manual spraying. This precision agriculture approach enhances monitoring efficiency, reduces pesticide wastage, and improves overall crop health.
